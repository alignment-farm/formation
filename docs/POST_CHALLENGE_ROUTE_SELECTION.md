# Post-challenge revision route selection

Status: **independently review-stable analytical selection, consumed by the
reviewed executable-prediction mechanism; this document licenses no further
proposal, prompt, interface, case packet, implementation, runner, participant-
model call, influence test, validation packet, or Formation claim**.

## Decision

Select a **first-output executable prediction rule tested against an
independent external result** for a separate mechanism proposal.

The cold model gets one declared authorship attempt after a consequential
experience. Its first output is preserved exactly. The intended authored object
is a small rule that maps public situation fields to a prediction. A frozen
interpreter evaluates valid rules, but it cannot repair or improve them.

Before authorship begins, the harness freezes every test input and assignment
used by the route. For the primary test, two processes then run from the same
public input:

```text
model-authored rule + test input -> frozen interpreter -> prediction
test input -> independent environment oracle -> actual result
```

The rule cannot choose an environment action or cause the actual result. The
interpreter cannot act for the practitioner. It only makes the rule's claim
observable, as a test runner makes a submitted function's output observable.
The environment result stays hidden until the prediction is committed.

A later cold call receives the exact parent output and the new occurrence and
authors one successor attempt. The first successor output is also preserved
exactly. A later conflicting test can repeat the same order for a second
successor. No output is replaced after its quality is known.

If a parent is malformed or cannot be decoded, its prediction is unavailable.
The preassigned external event still occurs, its result is recorded, and the
successor call still receives the exact raw parent and new occurrence. The
project may report that no falsification comparison was available for that
parent. It may not replace the parent or silently exclude the trajectory.

Revision is not earned because successor text differs. A candidate revision
would require a functional change from parent to successor that responds
specifically to the external result, improves preassigned cases where the
relation applies, and avoids changing matched cases where it does not. Separate
branches must show that another sample, raw result delivery, a static rule,
generic reconsideration, same-response generation, or visible-text copying did
not already produce the same functional change.

This is an authorship route. It does not yet test whether a successor rule
influences a later cold actor. The interpreter's predictions cannot count as
practitioner behavior or a Formation effect. A later influence mechanism would
need its own selection and successor-available versus successor-withheld
comparison.

## What the completed contact taught

The exact-draft contact required two identical challenge requests to reproduce
one exact candidate before it could issue a revision label. That combined two
different jobs:

1. revise a commitment because experience counted against it; and
2. emit identical wording on repeated open-ended generations.

World G returned different challenge strings. World H returned the same string
by copying its source. A prompt-mass control also showed that exact repetition
can preserve arbitrary visible text. Repeated wording was therefore neither a
neutral admission requirement nor evidence of revision.

The generic challenge supplied no new fact about whether the source draft
worked. The later call could respond to critique language, draft visibility, or
ordinary sampling. The selected route instead commits a prediction before an
independent environment result becomes visible.

This does not assume that external testing will cure copying. It makes copied
and constant rules fail or succeed on inputs fixed before the copied output
exists. If copying still explains the result, the route ends as another null.

## Where stability belongs

No favorable sample selection means that the first declared output stays in
the trajectory. It does not mean that a second generation must reproduce the
same bytes.

The selected route uses three narrower checks:

- The record preserves the exact parent and successor outputs and their causal
  parents. Neither can be replaced.
- The frozen interpreter gives the same valid rule and public input the same
  prediction every time. This is an instrument fact, not a model finding.
- Any later causal claim must recur under prospective assignment across
  trajectories. Every trajectory's first output remains in the predeclared
  denominator, including malformed, null, copied, constant, and wrong outputs.

The later mechanism proposal must name the repeated functional event,
assignment rule, aggregation rule, and denominator before contact. It may not
count only trajectories that produced convenient rules.

## The rule language must keep failure expressible

The post-contact boundary asks for a model-authored proposition with real scope
and a possible falsifier. Natural-language fields did not establish either
property. They also required a semantic governor to decide whether an awkward
string expressed the desired relation.

An executable prediction rule can make those requirements observable:

- Its declared public inputs define the situations over which it makes a
  claim.
- Running it commits a prediction before the external result is visible.
- A mismatched external result counts against that prediction.
- Held-out inputs test whether the function extends beyond the experienced
  episode.
- Matched inputs outside the relation test whether the function changes too
  broadly.

The next proposal must define a small, relation-neutral expression language.
At minimum, its semantic choices must include literal constants, public-field
selection, equality and inequality, Boolean composition, and conditional
composition. Those operations must support wrong, constant, copied, narrow,
and overbroad rules as well as potentially useful ones. They may not name the
target relation or expected prediction.

The semantic surface must allow every model-visible opaque action token and
visible-material control value to appear as a literal. Copying such a value
must therefore remain an executable constant or comparison that held-out cases
can expose. The language may not ban hexadecimal strings, long tokens, or the
specific shapes that dominated the completed contact.

A constrained response envelope may preserve JSON or expression syntax across
branches. That is interface instrumentation only. It cannot restrict the
operative expression to a short list of answer-shaped templates. If the model
still returns no decodable expression, the route records that failure and
continues the external event and successor authorship as described above.

The selection closes before a mechanism proposal if no such language can keep
copied and awkward rules executable without translating them into a better
rule or encoding the desired answer.

## Why this route is different from exact-draft challenge

The closed route preserved a first output and then asked a model to inspect it.
Its challenge was additional prompt content, not additional experience.

Here the parent makes a prediction about a test fixed before the parent exists.
An independent oracle supplies the actual result. The parent prediction cannot
cause that result, and neither the harness nor runtime chooses the test after
seeing the rule. Only then does the successor call occur.

A proposal fails if its external result merely restates the first occurrence,
if any test input is chosen after a live output is seen, or if the result
reveals answers for later transfer and non-transfer cases. All primary,
held-out, copying-control, and later-conflict inputs and assignments must be
frozen before the first authorship call. Their model-visible order may be
randomized only by a predeclared output-independent assignment.

## Routes considered

### Executable prediction rule

This route is selected because one authored object can be retained, evaluated,
falsified, and compared without semantic repair. The interpreter measures the
rule's predictions only. It cannot choose or apply practitioner actions.

### Natural-language proposition

This is not selected. The completed contact showed that prose fields could hold
copied tokens, source repetition, or varied counterevidence text. A new rubric
could improve appearance while leaving authorship unchanged.

Natural-language explanation may accompany a future rule as unscored evidence.
It cannot define the rule's executable meaning or determine eligibility.

### Behavioral change without an authored rule

This remains a required raw-history baseline, not the selected route. A cold
model may author a different rule after seeing a new result simply through
ordinary in-context learning. Parent-absent, result-absent, and same-response
comparisons must keep that explanation live.

### Model-authored inquiry

This is not selected. Letting the model choose the test would add probe
selection and could let a menu of probes encode the answer. Every test used by
the selected route is assigned independently of live model output.

### Competing-rule portfolio

This is not selected. Listing many possibilities and letting the runtime keep
the successful one would turn governance into the author. The route retains
one declared parent attempt and one declared attempt at each successor.

### Analytical stop

The route closes if the expression language cannot keep failure executable, if
the independent result cannot count against a prior prediction, or if the
required branches cannot separate functional revision from raw history,
sampling, static instruction, copying, and same-response generation.

## Causal order to preserve

The complete case menu, assignments, interpreter, environment oracle, and
result-withholding rule freeze before contact. The primary path is then:

```text
first consequential occurrence
  -> one parent-rule authorship call
  -> exact first output retained
  -> decode with the frozen language, or mark parent prediction unavailable
  -> evaluate the already-assigned test input if a rule is available
  -> reveal the independently computed environment result
  -> append an occurrence containing the committed prediction status and result
  -> one successor-rule authorship call using the exact raw parent
  -> exact first successor retained
  -> decode with the same frozen language, or mark unavailable
  -> evaluate parent and successor on the frozen case menu
```

The environment path for the already-assigned input is independent:

```text
already-assigned test input -> environment oracle -> sealed actual result
```

The sealed result may be computed before or after authorship, but it cannot be
revealed until the parent prediction is committed or marked unavailable. If no
parent prediction exists, the occurrence records that fact and the external
result; it does not call the result counterevidence to the parent.

A later revision cycle repeats the same order with the exact first successor as
parent, a separately preassigned conflicting opportunity, and the next first
successor. The governor and post-contact scorer have no causal path into any
authorship request.

## Comparisons the proposal must support

The proposal must show that each mandatory comparison can be constructed while
holding the frozen case menu, assignments, decoder, interpreter, budgets, and
first-output rule constant. If it cannot, the route closes or its claim is
lowered before contact.

### Authorship and sampling

1. Preserve every first output at its declared call position. No retry or
   replacement may depend on syntax, content, prediction, or later score.
2. Run a later call with the exact raw parent but without revealing the new
   external result. This measures another sample plus parent visibility without
   the new fact.
3. Reveal the new occurrence to a later call without delivering the parent.
   This measures raw-result authorship without parent influence.
4. Ask one call to produce parent and successor after receiving the complete
   history. This measures same-response generation without retained lineage
   between the two outputs.

### Functional comparison

5. Evaluate the exact parent and first successor with the same interpreter on
   every frozen primary, transfer, non-transfer, copying-control, and later-
   conflict input for which each rule is decodable.
6. Compare one frozen static rule through the same interpreter and case menu.
7. Keep unavailable parent and successor predictions in the reported
   denominator and preserve their exact raw outputs for condition-level
   comparison.

The route cannot issue a functional-revision label if the parent prediction on
the external test was unavailable. It may still report what the successor
authored after receiving the raw parent and occurrence.

### Copying and visible material

8. Repeat the relevant occurrence without delivering a parent rule.
9. Deliver a deterministic restatement of the external result without a
   model-authored parent.
10. Deliver a source-blind visible-material control through the same literal
    surface. Its size rule must be frozen without live semantic content.
11. Evaluate literal constants and rules that copy opaque action names on the
    frozen held-out inputs where those strings cannot supply the answer.

These comparisons carry forward repeated occurrence, restatement, prompt mass,
and arbitrary-copying explanations from the completed contact. Exact parent
copying is retention, not revision.

### Scope and repeated revision

12. Evaluate parent and successor on frozen inputs that share the relevant
    structure without copying the experienced answer.
13. Evaluate them on matched frozen inputs where the structure does not apply.
14. Use the separately preassigned conflicting opportunity to test whether the
    next first successor keeps, narrows, changes, suspends, or withdraws the
    rule.

These are authorship comparisons. They do not establish that a rule influenced
a later cold actor.

## Weakest useful observations

A later bounded exploration could report:

- whether each first output decoded as a rule;
- each valid rule's exact predictions on the frozen case menu;
- whether the independent result supported or contradicted the parent;
- whether the successor changed the parent function, and on which inputs;
- whether the same functional change appeared without result delivery, without
  parent delivery, or within one response;
- whether copied or constant rules failed held-out cases; and
- whether a later conflicting result produced another functional change.

These are per-condition observations. Different rule text is not revision. A
better successor function is not evidence that it influenced later practice.
No result here is a Formation effect.

## Loses-conditions

The route fails before contact if:

- the language, examples, case menu, decoder, interpreter, or oracle states the
  target relation or expected prediction;
- any primary, held-out, copying-control, or later-conflict input or assignment
  is chosen after a live output is available;
- the parent prediction can cause or select the environment result;
- the interpreter chooses, applies, or recommends a practitioner action;
- the result reveals answers for prospective transfer or non-transfer cases;
- repeated generation is required to make a parent or successor eligible;
- any first output is replaced because it is malformed, awkward, copied,
  constant, wrong, or hard to score;
- failed decoding prevents the assigned external event or successor authorship;
- failed decoding triggers a semantic retry or a translation into a rule;
- copied tokens and visible control values cannot remain executable literals;
- the runtime or harness repairs, summarizes, translates, or semantically
  selects a rule;
- only successful or decodable trajectories remain in the denominator;
- parent, successor, and controls use different languages, interpreters,
  constraints, budgets, or interfaces;
- governor refusal, scorer output, expected truth, or test score enters an
  authorship request outside the declared external occurrence;
- result-absent, parent-absent, same-response, repeated-occurrence,
  deterministic-restatement, visible-material, static-rule, transfer,
  non-transfer, or later-conflict comparisons cannot be separated while a
  stronger causal label is retained;
- copied tokens, executable syntax, or changed wording count as revision
  without functional tests;
- replication selects convenient trajectories or lacks a predeclared event,
  assignment, aggregation rule, and denominator;
- a null automatically opens prompt repair, resampling, model search, or a
  successor contact; or
- preserved bytes, executable rules, passing tests, or interpreter output are
  counted as practitioner development.

## Work licensed by this selection

Independent review found this selection stable. It licenses one separate
mechanism proposal for a first-output executable prediction rule tested against
an independent external result. That proposal must define the smallest
relation-neutral expression language and interpreter, version identity,
authority and information flow, complete pre-contact case assignment,
unavailable outcomes, mandatory comparisons, fixed denominator, and analytical
stop.

That one proposal license was consumed by the reviewed
[executable prediction revision mechanism](EXECUTABLE_PREDICTION_REVISION_MECHANISM.md).
The mechanism now owns the boundary before a separate strict-budget charter
decision.

The proposal must close if its language cannot keep copied and awkward rules
executable without repair, if its interpreter can act for the practitioner, or
if invalid parent output prevents the external event and successor authorship.

This selection does not license exact prompts, operational models, concrete
cases, numeric budgets, implementation, runners, participant-model calls,
later-practice influence testing, validation, or a Formation claim. The
consumed exact-draft charter licenses no rerun or successor.

## Review question

Independent reviewers must try to reduce the selected route to ordinary
in-context learning, sampling drift, raw history, static instruction, runtime
repair, executable-program substitution, visible-text copying, answer leakage,
semantic screening, or another admission gate. They must test whether invalid
parents still receive a developmental successor without being treated as
falsified, and whether the interpreter remains a measurement instrument rather
than the practitioner.

The two stable reviews license only the separate mechanism proposal described
above. They do not license a prompt, case packet, budget, implementation,
runner, participant-model call, influence test, or finding.

## Review record

Composer 2.5 and Grok 4.6 independently rejected two earlier drafts. The first
used an arbitrary “versioned artifact” that could affect a test only through
runtime interpretation or screening. The second selected an executable rule
but left favorable case selection open and could let the interpreter choose a

malformed parent still received an external event and successor.

The final revision freezes every case before contact, separates prediction from
the independent environment path, confines the interpreter to measurement,
keeps copied values executable as literals, and continues the event and
successor call after failed decoding.

text. They agreed that remaining choices—the exact language, decoder, case
