# Procedural-influence domain selection

Status: **analytical comparison complete; the selected phase-coupled route has
a stable proposal and conforming deterministic specimen, but no exploratory
charter or contact**.

## Selection rule

The next domain must make later model action depend on experience while leaving
the acquired relation unexecuted by the runtime. It must also be cheap enough
that raw persistence, direct authored practice, governance, ablation, lexical
decoys, and replication remain serious rather than ceremonial.

Three candidate domains were considered after the calibration-applicator draft
failed peer review.

| Candidate | Main advantage | Main identifying risk | Operational cost |
| --- | --- | --- | --- |
| Phase-coupled opaque control | Exact hidden rule, deterministic consequence, new action tokens, model remains later actor | May still reduce to a compact fact cue if later cases need only one action | Low |
| Executable coding repair | Natural procedure, strong external unit-test oracle, realistic transfer | Must first discover a repeatable error without reopening admission; cold static knowledge may solve it | Medium |
| Hidden-mechanic gridworld | Consequence-earned planning rule and multi-step transfer | New environment and trajectory divergence can obscure the causal comparison | Medium to high |

## Decision

Select phase-coupled opaque control for the next mechanism review.

It preserves the strongest parts of the existing calibration specimen: the
hidden assignment is exact, consequences are external, control tokens can be
changed completely, and the environment remains cheap. It changes the part
that failed. The runtime no longer converts a stored slot into an action. The
cold model must apply one model-authored binary family profile together with
public physics to a committed action pair before seeing the intermediate state.

Coding remains a strong later domain, but choosing it now would require an
exploratory error search. The gridworld remains useful if phase-coupled control
collapses into lookup or cannot create a clean fixed-history comparison.

Selection does not establish that the phase-coupled proposal is valid. It only
earns a concrete mechanism draft for adversarial review.

## Narrow ceiling

Ordinary two-slot calibration requires only one hidden value. A natural-language
candidate can name that value, and a later one-step increase can respond to it
as a salient direct cue. Adding a deterministic inverse applicator removes the
behavioral uncertainty rather than studying it.

Phase coupling does not make the acquired content richer than ordinary
calibration. Under the public physics, one observation identifies one binary
family profile. The domain is retained because a no-feedback two-control
commitment can make the model apply that bit through four linked public
judgments:

1. identify the increasing slot in the current phase;
2. invert it when the target is below position;
3. account for the phase change after a control action; and
4. choose a new opaque token occupying the required slot.

A correct candidate can state the profile. It cannot make those later actions
happen unless the cold model uses it. Any result is therefore bounded to
model-mediated application of situated family knowledge. It cannot establish
acquired procedure, strategy, craft, or far transfer.

## Rejection conditions

Reject or demote the domain before contact if review shows that:

- a public field or prompt supplies the realized phase-to-slot table;
- the candidate schema supplies the conditional branches rather than only a
  generic place for model-authored text;
- one prospective action can satisfy the comparison without phase change;
- raw occurrence is forced through a treatment-specific extractor;
- a governor wins only because ordinary authored practice cannot see public
  maintenance or scope evidence;
- action identifiers reveal phase, target direction, case family, or expected
  slot; or
- a deterministic runtime component chooses or recommends the later control.
