# Does staged model authorship change later action selectively?

Status: **frozen before contact under the session-wide human authorization**.

## Question

Does a model-written direct observation followed by a model-written effect
table improve later action on fresh matching devices while an exact-family gate
protects unrelated devices?

## Test

Two fresh source families each begin below-target movement with the target one
step lower. This prospectively pressures the second-slot result that defeated
direct table authorship. Each family produces one action and external result. A cold
model writes the directly observed slot and movement. Another cold call writes
the complete effect table from that exact observation. A direct author also
writes a table from the raw action and result.

Later action uses two new matching-family devices, one targeting above and one
below. Two unrelated opposite-rule families each provide one target above and
one below, giving four nonmatching cases per source. Every branch and case receives four
identical calls.

The seven branches are:

1. cold action with no retained material;
2. raw action and result;
3. direct model-authored table, delivered only to the matching family;
4. staged model-authored table, delivered only to the matching family;
5. removal of the exact staged table before delivery;
6. staged table delivered without the family gate; and
7. a supplied correct table delivered only to the matching family.

The harness passes model-authored bytes forward but never computes the table or
later action. The supplied table is an instruction-following diagnostic, not a
developmental branch.

The fixed schedule contains 344 calls: eight acquisition and authorship calls,
then 336 later actions. The physical ceiling is 352 attempts with at most eight
transport retries. Evidence is retained under
`evidence/staged-observation-action-chain-<run-id>/` and replayed before exit.

## Prospective result rule

The mechanism is `not_engaged` unless both direct observations and both staged
tables are exact, and the supplied table scores at least three of four on every
matching case.

The staged chain is a candidate only if both worlds satisfy all of these rules:

- staged gated delivery scores at least three of four in both matching
  directions;
- it beats cold, raw, direct authorship, and delivery removal by at least two
  actions in both matching directions;
- it loses no more than one action to cold on any unrelated case;
- every tested branch has at most one malformed or unavailable action per
  case; and
- across the eight unrelated cases, gated delivery prevents at least two
  errors caused by ungated delivery.

Otherwise the verdict is null or harmful. A candidate would justify a stricter
fresh validation. Formation remains null in this exploratory packet.
