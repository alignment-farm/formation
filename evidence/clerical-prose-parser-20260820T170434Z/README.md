# Clerical prose parser diagnostic

## Main result

The restricted clerk successfully parsed its own retained prose into a stable
record. The composed mechanism reached the frozen `pipeline_candidate`
verdict.

All four parser outputs contained the correct named effects. The deterministic
serializer produced all four calibrated first-then-second sentences exactly.
When the retained structural matcher selected those sentences, the participant
made 28 of 32 matching actions.

## What was tested

This diagnostic reused four clerk sentences and 12 later scope normalizations
from the staged clerical experiment. It verified the source packet and specimen
before contact.

Each source sentence already stated both control effects correctly but put the
second control first. The 4B clerk saw only that sentence pair. It extracted the
explicit first-control and second-control facts into named fields. It did not
see a sensory report, later device, controls, target, action request, answer, or
score.

A deterministic serializer placed those exact model-written values into the
sentence order that had passed the delivery calibration. The participant acted
on fresh family, device, position, and control identities.

Every participant response was valid. Every branch made 8 of 16 unrelated

The four missing matching actions came from the two retained normalization
errors in which an arched housing had been called smooth. The parser and
rendered record were not the cause of those misses.

## What this supports

This is evidence for a bounded learned clerical instrument. A restricted second
model can extract explicit experience facts into a stable record. A mechanical
serializer can then produce a participant-usable form, and an exact comparison
of two model-written structural fields can select it without using device
identity or action information.

The result also separates two jobs. Asking the clerk to infer an unstated
opposite effect was unreliable. Asking it to parse two already stated facts was
reliable in all four cases. That distinction tells us where model assistance is
useful and where the instrument still needs staged evidence processing.

## Limits and next step

This diagnostic assembled outputs from an earlier contact with new parser calls
and fresh participant cases. It is not a fresh end-to-end validation. It cannot
support Formation.

The mechanism has earned one strict fresh validation. That run should execute
the whole chain from source action through sensory transcription, explicit
effect prose, parsing, fixed rendering, later normalization, exact selection,
and action. It should include cold, raw, consequence-hidden, removal,
unselected, supplied, and non-transfer controls.
