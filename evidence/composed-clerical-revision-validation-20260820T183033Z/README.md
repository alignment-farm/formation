# Composed clerical revision validation

## Main result

The fresh composed mechanism passed every clerk, admission, transfer, removal,
and non-transfer comparison, but its frozen verdict is `not_engaged`.

The formal failure came from one raw-history control cell. On all three repeats,
the participant copied an old action token from the raw report. That token was
not allowed on the new device, so all three outputs were invalid. The frozen
scorer required every cell in every branch to contain at least two valid
actions. This one negative-control cell therefore stopped the verdict before
the mechanism criteria could apply.

The result cannot be promoted after contact. Formation remains null.

## The fresh task

Four new lineages each acquired two old control records. Those records acted on
fresh controls above and below the current position. The environment then
reversed all eight relations. Each participant followed the old record into a
movement that contradicted it.

The restricted 4B clerk wrote exposed and movement-hidden revision proposals.
A separate clerk call copied the proposed effect for the observed actuator.
The runtime checked source completeness, exact sensory copying, record shape,
the field projection, and equality with the observed effect.

Every proposal remained in lineage. Supported revisions could become version
2. Stale and hidden proposals were quarantined, leaving version 1 current.

Later devices used fresh identities, controls, positions, and targets. Matching
devices shared both visible features. Unrelated devices were novel or
recombined one feature from each known design.

## Why the frozen verdict stopped

The supplied branch made 48 of 48 matching actions and every supplied cell had
valid output. The admitted branch did the same. The apparatus was usable for
the claimed mechanism.

One exact raw-history request nevertheless returned an old control token on all
three repeats. Since later devices use fresh controls, the environment refused
that token. Invalid outputs remained in their denominator and the raw branch
scored them as wrong, as it should.

The additional rule that every negative-control cell must also contain two
valid actions did not protect the claimed mechanism. It let a failure of raw
history veto a comparison in which raw history was supposed to be a weak
control. Because that rule was frozen, this packet remains `not_engaged`.

## What this supports and what it does not

As an observation, the fresh run reproduces the whole proposed causal chain:
counterexperience produced exact revisions, the composed gate admitted only
source-supported records, admitted revisions caused perfect matching action,
removal erased the benefit, and structural matching preserved unrelated
behavior.

The frozen validation verdict does not support the mechanism because its
engagement rule failed. A successor would need new lineages and a prospective
scorer. Invalid control outputs should remain wrong in their fixed denominator,
but only the supplied and claimed-mechanism cells should decide whether the
participant interface is engaged.

Even a supported successor would remain bounded to this small domain. Supplied
guidance tied the learned mechanism. This result does not establish autonomous
model development, long-horizon revision, net value, or Formation.
