# Structural record delivery calibration

## Main result

A short effect sentence gave the participant a reliable delivery interface. It
made all 32 matching actions. The frozen verdict is `usable_form_found`.

The current-family table used as the engagement check also made all 32 actions.
None of the three other JSON forms met the frozen threshold.

## What was tested

This experiment supplied the correct control relation. It did not ask a model
to learn, encode, or classify experience.

Each later device had fresh family, device, and control strings. The harness
presented the same correct relation in five forms: the string container used in
the first clerical experiment, a scoped JSON record, a direct JSON effect
table, a short sentence, and the previously successful table keyed to the
current family. A cold condition received no relation.

## What this supports

The first clerical experiment failed its supplied-record ceiling because its
new record container was not a reliable participant interface. This
calibration repairs that apparatus problem. A selected sentence can now serve
as the payload in the next clerical experiment.

The result does not prefer prose in general. It compares five exact forms in
one small action interface. It also does not show acquisition or development,
because the harness supplied every correct relation.

The next experiment can keep scope classification separate from action. The
clerical model can normalize a restricted sensory report, write an effect
sentence, and normalize a later device description. The harness can then make
an exact two-feature comparison and deliver only the model-written sentence.
