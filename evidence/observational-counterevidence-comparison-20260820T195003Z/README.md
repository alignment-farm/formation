# Observational counterevidence comparison

## Main result

The paired comparison passed its frozen validation. The verdict is `supported`.
Formation remains null.

A public runtime exploration selected the first valid control without knowing
its effect. The environment movement contradicted the current version-2 record
in all four lineages. A restricted clerk wrote four exact version-3 records.
The observation-grounded governor admitted all four; the action-attributed
governor quarantined all four because version 2 had not chosen the exploratory
actions.

Later action cleanly followed that difference. Observation-grounded
exploratory revisions made 48 of 48 matching actions. Action-attributed
handling and removal each made only the 24 unchanged-scope actions. Supplied
correct guidance also made 48 of 48.

## The source comparison

Each lineage began from the same supported parent packet with current version-2
records for scopes A and B. Only A's environment relation changed.

Two source occurrences forked from that parent:

- A target-directed participant received version 2 and chose an action for its
  target.
- A declared runtime exploration committed the first valid control. It did not
  receive the control effect, expected movement, or later answer.

Both actions received ordinary environment results. All four target-directed
actions followed version 2's target policy. The four exploratory actions were
not attributed to version 2 by definition. Every result nevertheless
contradicted version 2's effect claim for the selected control.

The observational exploratory branch made 12 of 24 unrelated actions, exactly
the cold score. Its matcher delivered no record to any unrelated request.

All participant outputs were valid. No branch needed an engagement exception.

## What this supports

The result supports observation-grounded revision from deliberate exploration
in this small deterministic domain. A runtime can select an action for the
purpose of learning, observe an external consequence, ask a restricted clerk
to represent the relation, and admit that revision without pretending the old
record caused the exploratory choice.

The governor distinction is causal rather than cosmetic. Both governors saw
the same complete proposed records and external contradictions. They differed
only on whether action attribution was required. That decision changed later A
action, while B and unrelated cases stayed unchanged.

This also resolves the mechanism question exposed by the preceding null. The
earlier occurrence with a non-attributed action was valid observational
counterevidence, but it could not satisfy an action-attributed claim. The two
claims now have separate prospective evidence.

## What this does not support

The exploration policy deterministically chose a valid control in a tiny two-
control world. The environment was deterministic and every contradictory
movement was trustworthy. A more permissive observational governor may be
vulnerable to noisy, transient, or contested consequences.

Known-correct supplied guidance tied the learned mechanism. The result does not
show superiority over static instruction, large-catalog behavior, durability
under repeated conflict, net value, exceptional practice, or Formation.

The next empirical problem is counterevidence accumulation. The substrate must
distinguish a stable changed relation from one isolated contradictory
observation before a permissive observational governor is safe beyond this
deterministic world.
