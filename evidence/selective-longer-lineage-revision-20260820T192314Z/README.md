# Selective longer-lineage revision

## Main result

The longer-lineage mechanism passed every record, admission, chronology,
transfer, interference, removal, and non-transfer threshold. Its frozen verdict
is nevertheless `null` because only three of four third-occurrence actions
followed the current version-2 policy. Formation remains null.

The fourth action was valid and its environment result contradicted the exact
version-2 claim for the selected control. It therefore supplied enough sensory
evidence for the composed gate, but it did not show that version 2 had guided
the action. The frozen scorer required both facts on all four lineages. That
requirement missed by one and cannot be changed after contact.

## The continued lineage

This run loaded the exact supported parent packet rather than asking either
model to reconstruct it. Each of its four lineages began with two admitted
version-2 records, A and B.

Those records first guided 47 of 48 actions on new devices and controls. Only A
then changed again. Its real relation returned to the version-1 relation. The
participant acted once from the current version-2 sentence, and the environment
reported what the selected control actually did.

A restricted 4B clerk represented each new occurrence. The runtime applied the
same source, transcription, shape, selected-field, and effect-equality checks as
the supported parent mechanism. Scope B received no new consequence and stayed
at version 2.

Because A returned to its first relation, its version-3 record has the same
effect fields as version 1. It is not the same developmental object. It cites a
new source occurrence, has a new version coordinate, and supersedes version 2
without editing either earlier version.

The current catalog made 21 of 24 A actions under version 3 and all 24 B
actions under the unchanged version 2. Supplied correct records made the same

The stale, hidden, and removal branches made none of the 24 A actions because

removing A's new version did not erase or corrupt B.

version 3, B received version 2, and unrelated cases received no record.

## Unrelated behavior

Every branch made 12 of 24 unrelated actions. The learned normalizer selected
no record for any novel or recombined device. The mechanism therefore remained
silent on all unrelated requests and preserved the cold score exactly.

## Why the frozen verdict is null

Three third-occurrence actions followed version 2 toward the target and then
moved in the opposite direction from its prediction. In the fourth lineage,
the participant chose the other valid control. That action happened to reach
the target under the changed environment, but its observed movement still
contradicted version 2's claim about that selected control.

These are two different facts:

- **policy attribution:** did the current record guide the control choice for
  the target?
- **claim contradiction:** did the observed consequence contradict what the
  current record said that selected control would do?

The occurrence had claim contradiction but not policy attribution. The frozen
test required both in all four lineages, so the formal result is null even
though the later selective chronology comparisons passed.

## What this supports and what it does not

As an observation, the run shows that the apparatus can preserve two records,
create a third source-bound version for only one, keep the other at version 2,
select the intended versions on all 72 later calls, and retain the expected
removal and non-transfer contrasts.

The frozen verdict does not support the longer-lineage mechanism. In
particular, one lineage lacks causal evidence that the prior record produced
the action leading to its correction. That missing attribution cannot be
supplied by the later success.

The result exposes the next mechanism question. An ordinary experience record
contains the committed action and its external consequence whether or not the
action followed a retained target policy. Governance must state whether a
complete selected-effect contradiction may warrant observational revision, or
whether revision is restricted to errors causally attributable to the current
record. Those policies answer different questions and should not be blended by
another retrospective scorer change.

This result does not establish long-horizon durability, large-catalog behavior,
superiority over supplied guidance, net value, or Formation.
